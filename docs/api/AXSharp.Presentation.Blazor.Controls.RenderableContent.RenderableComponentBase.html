    AddToPolling(ITwinElement, int)

    Adds element to the polling queue.

    [!IMPORTANT] This method should be overriden in the derived class to limit the number of elements to be polled for large objects. All inner primitive types of the element will be added to the polling queue by default. When creating override remember to add the polled element to the PolledElements set that is needed for removal of the element from the polling queue once the component is disposed.
